# 当前位置天气查询

通过两个 function calling 工具组合完成天气查询（非 MCP，由模型在对话中自行调用）：

| 工具 | 作用 | 参数 |
| --- | --- | --- |
| `get-current-location` | 按网络出口 IP 定位当前位置 | 无 |
| `get-weather` | 按城市名或经纬度查询实时天气 | `city`（城市名）或 `latitude` + `longitude`（经纬度），二选一 |

两个天气数据源均为开源免费服务：Open-Meteo（主源）与 wttr.in（主源失败时自动兜底）。

## 工作流（必须严格按此顺序）

### 场景 1：用户问当前位置的天气（"我这边现在什么天气"、"现在冷吗"、"要带伞吗"）

1. 先调用 `get-current-location`（不要向用户追问城市，也不要把经纬度暴露给用户）；
2. 拿到返回的 `latitude`、`longitude` 后，再调用 `get-weather`，传入经纬度；
3. 根据工具返回的真实数据组织回答。

### 场景 2：用户指定了城市（"北京天气怎么样"、"上海下雨吗"）

1. 直接调用 `get-weather`，传入 `city` 参数，不需要先定位。

### 场景 3：与天气无关（"现在几点"、"今天星期几"、"你好"）

1. 不要调用任何工具，直接回答。

## 回答要求

- 必须基于工具返回的真实数据回答，禁止编造温度或天气现象；
- 用简洁中文，包含：天气现象、温度（℃）、相对湿度（%）、风速（km/h）；
- 如果是雨、雪等天气，主动提醒携带雨具/注意保暖。

## 示例

**用户**：我这边现在天气怎么样？
**模型**：（调用 get-current-location）→（用经纬度调用 get-weather）→
"当前位置天气为多云，气温 24℃，相对湿度 62%，风速 8 km/h，适合出行。"

**用户**：现在几点了？
**模型**：不调用任何工具，直接回答当前时间相关内容。

## 验证清单

- [ ] 问当前位置天气时，依次命中 `get-current-location` → `get-weather`；
- [ ] 问指定城市天气时，只命中 `get-weather` 且参数含正确城市名；
- [ ] 问时间/日期/问候时，不命中任何工具。
