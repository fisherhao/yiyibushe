# 每日科技新闻速递

通过 1 个 function calling 工具抓取、由对话模型完成翻译与摘要（非 MCP）：

| 工具 | 作用 | 参数 |
| --- | --- | --- |
| `get-tech-news` | 抓取最新科技新闻条目（标题、链接、来源、发布时间） | 无 |

工具内部按"主源 → 兜底"顺序取数，并带 10 分钟内存缓存：

1. **GDELT DOC 2.0**（主源）：全球新闻聚合，多语种科技报道；
2. **Hacker News 官方 API**（兜底 1）：科技社区热榜，稳定可靠；
3. **Wikinews RSS**（兜底 2）：维基新闻·已发布分类。任一源成功即返回。

翻译不需要额外翻译服务：外文标题和摘要直接由对话模型（当前 qwen-flash）翻译并提炼要点。

## 工作流（必须严格按此顺序）

### 场景 1：用户要看科技新闻（"今天有什么科技新闻"、"最近科技圈有啥大事"）

1. 调用 `get-tech-news`（无参数，工具自动选源并返回多条原始新闻 JSON）；
2. 从返回条目中挑选 **3-5 条最有价值、彼此不重复** 的科技新闻；
3. 外文标题先翻译成中文，再为每条写一句话核心要点（基于标题与已知背景，禁止编造原文没有的事实）；
4. 按下方格式输出。

### 场景 2：与新闻无关（"现在几点"、"讲个笑话"、"天气怎么样"）

1. 不要调用本工具。问天气走 current-weather 技能；其他问题直接回答。

## 输出格式（严格遵守）

```
📰 今日科技新闻速递（共 N 条）

1. 【中文标题】
   来源：xxx ｜ 原标题（如外文）：xxx
   一句话总结：……
   链接：https://...

2. ……
```

要求：

- 每条必须包含：中文标题、来源、一句话总结、链接；
- 全部中文输出（专有名词可保留英文，如 OpenAI、GPU）；
- 不要罗列超过 5 条，不要输出工具返回的原始 JSON；
- 如果工具返回为空或报错，如实告知"今日新闻获取失败"，不要编造新闻。

## 示例

**用户**：给我看看今天有什么科技新闻
**模型**：（调用 get-tech-news）→
"📰 今日科技新闻速递（共 3 条）
1. 【F-Droid 2.0 发布：安卓自由生态的新篇章】
   来源：f-droid.org
   一句话总结：安卓开源应用商店 F-Droid 发布 2.0 大版本。
   链接：https://f-droid.org/..."

**用户**：讲个笑话吧
**模型**：不调用任何工具，直接讲笑话。
